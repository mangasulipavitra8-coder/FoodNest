# FoodNest 🍔

FoodNest is an online food ordering web application that allows users to browse restaurants, view menus, add food items to a cart, place orders, and view order history.

## Features

- User Registration and Login
- Browse Restaurants
- Search Restaurants and Food
- View Restaurant Menus
- Add Items to Cart
- Checkout and Order Placement
- Online Payment Integration
- Order History
- User Profile
- Logout

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat
- Eclipse IDE
