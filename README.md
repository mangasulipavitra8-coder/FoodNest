# 🍔 FoodNest

FoodNest is an online food ordering web application developed from scratch using Java Full Stack technologies. It allows users to browse restaurants, view menus, search for food, add items to a cart, place orders, make online payments, and view their order history.

## 🚀 Features

### 👤 User Module
- User Registration and Login
- User Authentication
- Session Management
- User Profile
- Browse Restaurants
- Search Restaurants and Food
- View Restaurant Menus
- Logout

### 🛒 Cart & Order Module
- Add Food Items to Cart
- View Cart
- Update Cart Items
- Remove Items from Cart
- Checkout
- Order Placement
- Order History

### 💳 Payment Module
- Online Payment Integration
- Razorpay Payment Gateway
- Payment Processing
- Order Confirmation

## ⚙️ Installation

### Prerequisites

- Java JDK 21
- Eclipse IDE
- Apache Tomcat
- MySQL
- MySQL Connector/J
- Razorpay Account

### Steps

1. Clone the repository.
2. Import the FoodNest project into Eclipse IDE.
3. Configure Apache Tomcat Server.
4. Create the required MySQL database.
5. Create/import the required database tables and data.
6. Configure the database connection details in the project.
7. Add the MySQL Connector/J dependency.
8. Configure the Razorpay payment integration.
9. Run the project using Apache Tomcat.
10. Open the application in your browser.
